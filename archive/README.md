# Archive

This folder keeps the historical FORGE build trail out of the repository front page while preserving it for audit, regression, and continuity.

Archived material includes:

- historical plans and release checklists
- upload manifests and packaging notes
- validation reports and harnesses
- contract fixtures, trace samples, and generated evidence
- hosted resolver and local preview experiments

The active install/runtime files remain at the repository root:

- `README.md`
- `INSTALL.md`
- `idb-drawer.user.js`
- `assets/`
- `netsuite/`
- `src/contracts/`
- `package.json`
